Render & Telegram

Rendering runs in aerender, so After Effects stays usable and the progress percentage is real. Bots can upload up to 50 MB.

Send with your own account

A bot is capped at 50 MB by Telegram. Your own account may upload 2 GB. This signs in as you — the session is stored in settings.json in plain text and is full access to your account, so treat that file like a password.

A bot on Telegram's own servers may upload 50 MB. Running your own Bot API server raises that to 2 GB. The api_id and api_hash are what that server needs to start — entering them here changes nothing on its own. Fill in API server with the address it listens on, e.g. http://localhost:8081.
